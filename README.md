# The Glow Theory

> **A little love, a lot of glow.** 

The Glow Theory is a fictional beauty and skincare brand created as a full-stack e-commerce portfolio project. It is a learning demo, not a real store: products, prices, accounts, checkout, delivery options, and orders will be simulated. No real purchases or deliveries will be made.

This project is being built to practise planning, designing, and developing a complete web application from the customer-facing experience through to a Java Spring Boot backend and PostgreSQL database. Everything described as planned below is **not implemented yet**.

## The brand

The Glow Theory is imagined as a warm, modern, welcoming skincare and beauty brand. Its visual identity will centre on a simple line drawing of a woman's side profile—the outline of a face rather than a detailed portrait—paired with the brand name. The overall look should feel polished and soft, with a glow-inspired palette, thoughtful typography, and clear, easy-to-use pages.

The exact logo, colours, fonts, and final tagline are still design decisions to make during the project.

## Planned collections and campaign imagery

The demo catalogue is planned to include skincare and beauty collections such as:

- **Everyday Glow** — approachable everyday skincare essentials.
- **Glow Rituals** — products grouped into simple routines.
- **Glow Kits & Bundles** — curated combinations for a routine or gift.
- **The Kiddies Range** — a separate, age-appropriate collection presented with care and clear product information.

Campaign and product imagery will feature models with a range of skin tones and appearances so the brand feels inclusive and the products can be shown in use. The models and campaign content are part of the fictional brand presentation; no real endorsement or product claim is implied. All product descriptions and images will be demo content.

## Planned technology

The intended stack is:

- **HTML, CSS, and JavaScript** for the frontend.
- **Java with Spring Boot** for the backend and application programming interface.
- **PostgreSQL** for storing demo data.
- **Maven** for managing and building the Java backend project.
- **Git** for version control and tracking the project as it develops.

The project will be built in stages. The stack and architecture may be refined as learning progresses, and the README roadmap should be updated to reflect what is actually complete.

## Planned features

These features are ideas for the project roadmap, not working functionality yet:

- A responsive home page introducing The Glow Theory and its collections.
- A product catalogue with product details, categories, prices, and demo stock information.
- A **Find Your Glow** quiz that asks about a shopper's preferences and suggests a suitable demo routine or products. Suggestions are for the project experience and are not medical advice.
- A shopping cart where visitors can review and adjust demo items.
- A simulated checkout flow with delivery choices labelled **The Courier Guy** and **PAXI**. These are display options only; there will be no real courier integration, payment processing, or delivery.
- Customer account screens for sign-up, sign-in, and viewing demo order history.
- Promotions and product bundles to demonstrate discounts and curated sets.
- An admin dashboard for managing demo products, collections, and promotions. Admin pages will be protected by user roles in the application.
